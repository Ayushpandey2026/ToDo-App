# ✅ React Todo App

A clean, responsive, and efficient **Todo List Application** built with React. Manage your daily tasks with ease — add, mark complete, delete, and clear all tasks. LocalStorage support ensures your tasks stay even after refreshing the page.

## 🚀 Live Demo

> Coming soon...

## 📌 Features

- ✅ Add new tasks with validation
- ❎ Prevents adding duplicate or empty tasks
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks in one click
- ☑️ Mark tasks as completed (checkbox style)
- 📅 Shows current date
